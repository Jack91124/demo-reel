demo-reel renders a terminal — or a Claude Code / Codex session — from a TOML file into an MP4 or GIF. No screen recording, no headless browser, no ttyd. Same file in, byte-identical frames out.

GitHub → pip install demo-reel 
pip install demo-reel
demoreel from-session ~/.claude/projects/-Users-me-app/3f2a.jsonl \
  -o demos/bugfix.toml --render demo.mp4

Screen recording is the wrong tool

A recorded demo can't be reviewed in a pull request, can't be re-rendered after a copy change, and can't be reproduced by anyone else. A demo written as a text file can do all three.

What it renders

Shell transcripts

cmd steps type character by character; out steps print line by line. Prompts, colours, banners, captions.

Agent sessions

user / assistant / tool steps. Point from-session at a real Claude Code or Codex JSONL log and it writes the TOML for you.

Six themes

github-dark, dracula, nord, light, midnight, solarized — 19 colour keys each, overridable per script.

CJK done properly

Double-width cells for Chinese/Japanese/Korean, separate glyph fallback fonts, and truncation measured in terminal cells instead of characters.

Compared to what already exists

Every alternative either needs a browser, records a live shell (so it is never reproducible), or has been abandoned — and none of them can draw an agent conversation.

Install

Python 3.11+, ffmpeg on PATH, Pillow (installed automatically). Runs on Windows, macOS and Linux.

# macOS          brew install ffmpeg
# Ubuntu/Debian  sudo apt install ffmpeg
# Windows        winget install Gyan.FFmpeg

pip install demo-reel
demoreel --help

The format is the point

[[steps]]
type = "user"
label = "you"
text = "auth middleware accepts expired tokens, fix it"

[[steps]]
type = "tool"
label = "Read"
call = "src/auth/middleware.ts"
lines = ["1  export async function verify(req: Request) {",
         "3    return decode(t)   // no exp check"]

[[steps]]
type = "assistant"
label = "claude"
text = "The decoder ignores exp. I will reject tokens whose exp is in the past."

Change a line, re-render, commit. The diff shows exactly what changed in the demo — which is something a 4 MB GIF in your repo will never do.

Honest limitations

Not an emulator

It draws a character grid; it does not run your program. Real ANSI art, cursor addressing or a TUI redrawing itself needs VHS.

Two session formats

Claude Code and Codex today. Gemini CLI, Cursor and DSH are open issues — DSH logs are zstd-compressed, which needs a decoder dependency we have not added.
